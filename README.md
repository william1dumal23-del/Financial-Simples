Dashboard de Análise de Vendas | Power BI

Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático da Digital Innovation One (DIO), com o objetivo de aplicar conhecimentos de análise de dados e visualização de informações utilizando o Microsoft Power BI.

O dashboard apresenta indicadores comerciais, permitindo analisar o faturamento, o volume de unidades vendidas, os descontos, os custos e o desempenho dos produtos e segmentos de mercado.

Objetivos

Analisar o desempenho das vendas.

Acompanhar a evolução das vendas ao longo dos meses.

Identificar os produtos com maior faturamento.

Comparar as vendas por segmento de mercado.

Avaliar os principais indicadores financeiros.

Desenvolver habilidades na construção de dashboards interativos.
